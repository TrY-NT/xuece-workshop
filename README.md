# 学测工坊（xuece-workshop）

高校专业课程学习测评云平台，Web应用系统综合实训项目（第8组）。

## 项目简介

面向高校学生课程自主学习与自测场景，提供课程资源学习、在线测评、个人中心与错题本等核心功能，管理端提供课程资源、题库试卷、用户管理与学习数据统计，扩展功能包括教师在线答疑、课程问卷、AI知识点检索与错题智能推题。

## 技术栈

- 后端：Spring Boot 3 + MySQL
- 管理后台：Vue3 + TypeScript + vue3-element-admin
- 学习端：Vue3 + TypeScript
- 接口文档：Apifox（RESTful + JWT）

## 目录结构

| 目录 | 用途 |
| --- | --- |
| docs/ | 需求分析、设计、接口、测试与部署文档 |
| backend/ | Spring Boot 3 后端工程 |
| frontend-admin/ | vue3-element-admin 管理后台工程 |
| frontend-web/ | Vue3+TypeScript 学习端工程 |
| database/ | 建表脚本、初始化数据、数据字典 |
| api/ | Apifox 导出文件与接口约定 |
| tests/ | 测试用例、接口测试脚本 |
| deploy/ | 部署配置与部署说明 |
